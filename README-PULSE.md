# PULSE Android

PULSE transforma sinais públicos em eventos urbanos compreensíveis.

## V1
- Android APK, local-first.
- 7 conectores: SPTrans, CET, Metrô SP, CPTEC/INPE, Open-Meteo, CETESB e CEMADEN.
- Source Health: LIVE / DEGRADED / AUTH REQUIRED / OFFLINE.
- SQLite local com 48h de snapshots.
- Time Machine.
- Anomaly engine local.
- Live Map com ônibus SPTrans.
- Live Lens com câmera traseira.
- AI Observer opcional.
- Chaves criptografadas com Android Keystore.
- Nenhum dado simulado é marcado como LIVE.

## SPTrans
Insira o token Olho Vivo no menu Settings do app. Sem token, a camada permanece AUTH REQUIRED.
